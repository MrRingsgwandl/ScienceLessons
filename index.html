Teacher & Host Tip: Creating More Lessons

To add your next lesson, simply build/rename a new HTML file (e.g., week2_elliptical.html), place it in the same repository, and duplicate the Card block in this index code to link to it!

GitHub Pages Setup Flow:

  1. Ensure this directory structure exists in your GitHub repository:
  2. ├── index.html
    └── week1_cosmic_tether.html
  3. Go to your GitHub Repository Settings → Pages tab.
  4. Choose Deploy from a branch, select your main branch, and click Save.
  5. Your lessons will now be live on your custom web address!
